# 데이터 지표 사전 (Metrics Dictionary)

> ⚠️ **포트폴리오용 마스킹 안내**
> 원본 파일은 사내 데이터 지표 정의 사전으로, 지표명(한국어/영어/약어) → 정의/산식 → 산출 테이블을 매핑합니다.
> 실제 운영본은 커머스/수익/프로덕트/마케팅/물류/운영 등 도메인별 **수백 개 지표와 사내 재무 산식·테이블명**을 포함하지만,
> 영업기밀에 해당하여 본 포트폴리오 사본에서는 **구조만 남기고 내용을 가상 예시로 대체**했습니다.

이 문서는 사용자가 지표명(한국어/영어/약어)으로 질문할 때 올바른 테이블을 안내하기 위한 지표 정의 사전입니다.
플러그인은 SessionStart 시점에 이 사전을 컨텍스트로 로드하여, 분석 워크플로우에서 "지표 → 테이블" 매핑에 활용합니다.

## 1. 지표 약어 매핑 (Alias → 풀네임)

| 약어 | 한국어 지표명 | 영어 지표명 |
|------|-------------|------------|
| GMV  | 거래금액      | Gross Merchandise Value |
| DAU/WAU/MAU | 일/주/월간 활성 사용자 | Daily/Weekly/Monthly Active Users |
| CVR  | 전환율        | Conversion Rate |
| ARPPU | 객단가       | Average Revenue Per Paid User |
| ROAS | 광고비 대비 거래액 | Return on Ad Spend |
| …    | (이하 생략 — 원본에는 수십 개 약어가 정의됨) | … |

## 2. 도메인별 지표 정의 (구조 예시)

원본은 아래 도메인 섹션으로 구성되며, 각 섹션은 `지표명 | 영어명 | 정의/산식 | 산출 테이블` 형태의 표를 가집니다.

- **커머스 지표** — 거래/할인/수익 (예: 거래금액, 할인율, 수익성 지표)
- **프로덕트 지표** — 활성 사용자, 방문→구매 전환율, 상품상세 방문자 수
- **마케팅 지표** — 가입자 수, 첫 구매자 수, 광고 효율(ROAS/CPA/CTR/CVR)
- **물류·운영 지표** — 출고준수율, 교환/환불률, 상담 만족도(CSAT)
- **온보딩 지표 (분석팀 전용)** — 가입자 수, 첫구매자 수, 가입→첫구매 소요일

### 지표 정의 행 — 가상 예시 1

| 지표명 (KOR) | 영어명 | 정의 / 컬럼 | 산출 테이블 |
|---|---|---|---|
| 가입자 수 | # Registrations | `COUNT(DISTINCT uid)` (가입일 기준) | `analytics.onboard_registration` |

### 지표 정의 행 — 가상 예시 2

| 지표명 (KOR) | 영어명 | 정의 / 컬럼 | 산출 테이블 |
|---|---|---|---|
| 첫구매자 수 | # First Buyers | 생애 첫구매(`purchase_cnt = 1`) 회원 수 | `analytics.onboard_first_order` |

## 3. 가드레일 / 안티 패턴 (분석 시 주의 — 구조 예시)

- 원천 테이블의 **상태 코드 필터**를 누락하면 환불/취소 건이 집계에 포함될 수 있음
- **백필 row 제외 조건**(예: `dt = 처리일`) 누락 주의
- 분석팀 출력 스키마(`analytics.*`)는 출력 전용 — DAG의 source로 쓰면 순환 의존 위험
- 모든 SQL은 KST 변환 템플릿 사용 (`logical_date.in_timezone("Asia/Seoul")`)

> 실제 사전에는 위 구조로 도메인별 수백 개 지표 정의와 산출 테이블 매핑이 채워져 있습니다.
