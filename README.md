저는 **제품 분석, 비즈니스 분석, 데이터 엔지니어링, AI 기반 데이터 제품**의 접점에서 일하는 데이터 분석가입니다.

복잡한 데이터를 **신뢰할 수 있는 데이터 자산**으로 만들고, **누구나 활용 가능한 분석 도구**를 만들어 **데이터 리터러시를 높이는 일**에 관심이 있습니다.

또한, 단순히 데이터를 분석하는 것에서 그치지 않고, **문제를 정의하고 데이터 기반 해결책을 제시하여 실제 비즈니스 성과로 연결하는 일**에 자신이 있습니다.

<br/>

## 🚀 What I Do

- 📊 **제품·그로스 분석** — 퍼널, 코호트, 리텐션, 고객 행동 분석으로 제품의 성장 기회를 발굴합니다.
- 🏗️ **데이터 마트 및 파이프라인 자동화** — Airflow·Databricks 기반 자동화 파이프라인과 재사용 가능한 분석 마트를 처음부터 끝까지 구축합니다.
- 🎯 **데이터 품질 및 거버넌스** — 일관된 지표 정의와 데이터 정합성 검증을 통해 조직이 신뢰할 수 있는 데이터 기준을 만듭니다.
- 🤖 **AI 기반 셀프서브 분석** — LLM Agent와 Text-to-SQL을 활용해 누구나 데이터에 쉽게 접근하고 활용할 수 있는 환경을 만듭니다.
- 📈 **비즈니스 의사결정 지원** — 예측 및 시뮬레이션 모델을 통해 성장 기회, 가격 전략, 수익성을 검토합니다.
