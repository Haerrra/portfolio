# Business Problem

## Background

ACME 서비스 내 혜택 기반 제품이 지속적으로 증가하면서 이벤트·회원혜택 페이지는 단순 나열형 구조만으로 사용자의 반복 참여를 유도하기 어려운 상황이었다.

특히 각 기능이 독립적으로 운영되면서 기능 간 연결성이 부족했고, 사용자는 특정 기능만 이용한 뒤 이탈하는 패턴을 보였다.

## Key Issues

### 유입

* 이벤트·회원혜택 페이지 WAU는 일정 규모 형성
* 홈 추천 영역 퀵버튼 CTR 약 0.05%
* 마이페이지 → 이벤트 페이지 CTR 약 7.6%

### 참여

일부 기능을 제외한 대부분의 기능의 클릭 전환율이 낮은 수준을 보였다.

예시

| 기능    | 클릭 전환율 |
| ----- | ------ |
| 출석체크  | 78%    |
| 콘텐츠 좋아요 | 28%    |
| 퀴즈 이벤트   | 24%    |
| 기타 기능 | 10% 미만 |

### 재방문

| 지표      | 리텐션    |
| ------- | ------ |
| Daily   | 70.0%  |
| Weekly  | 46.67% |
| Monthly | 29.62% |

단기 참여는 발생하지만 장기적인 재방문 및 습관화에는 한계가 존재하였다.

---

# Solution

사용자의 참여 여정을 중심으로 이벤트·회원혜택 페이지를 재설계하였다.

기존의 기능 나열 구조를 벗어나,

유입 → 탐색 → 참여 → 보상 → 재참여 → 재방문

흐름을 중심으로 구조를 개편하였다.

주요 개선 사항

* 기능 간 Cross Activation 강화
* 미션형 구조 도입
* 참여 현황 시각화
* 보상 피드백 강화
* 추천 기능 추가
* 누적 리워드 제공
* 타 사용자 참여 현황 노출

# Analysis Design

## Challenge

배포 과정에서 실험군/대조군 기반 A/B Test가 수행되지 않았다.

따라서 개편 효과를 직접 측정할 수 없는 상황이었다.

## Approach

준실험(Quasi-Experiment) 방법론을 적용하였다.

분석 절차

1. User Matching
2. Balance Check
3. Difference-in-Differences (DiD)
4. Event Study

# Data

## Matching Variables

| 행동 데이터        | 정의                |
| ------------- | ----------------- |
| 방문 수          | 홈 추천 영역 방문 수          |
| 상품 클릭 수       | 상품 클릭 수           |
| 구매 수          | 출고 요청 기준 주문 수     |
| 이벤트·회원혜택 방문 수 | 이벤트·회원혜택 페이지 방문 수 |
| 이벤트·회원혜택 참여 수 | 혜택 기능 참여 수        |

## Treatment Group

배포일에 이벤트·회원혜택 페이지를 방문한 사용자

## Control Group

배포일에 이벤트·회원혜택 페이지를 방문하지 않은 사용자

# Difference-in-Differences Result

## Main Result

DiD 분석 결과, 개편 이후 실험군의 행동 지표가 대조군 대비 유의미하게 증가하였다.

| Metric            | Lift    |
| ----------------- | ------- |
| 방문 수              | +65.72% |
| 이벤트·회원혜택 페이지 방문 수 | +48.77% |
| 이벤트·회원혜택 참여 수     | +69.99% |

모든 주요 지표에서 통계적으로 유의미한 증가가 확인되었다.

# Event Study

배포 효과의 지속성을 확인하기 위해 Event Study 분석을 수행하였다.

## Findings

* 효과는 배포 직후 가장 크게 나타남
* D+1 Day에서 Peak 발생
* D+2 Day 이후 효과 감소
* 일부 참여 지표는 감소 반전 발생

# Key Insights

### Insight 1

개편은 사용자 방문 및 참여 행동 증가에 효과적이었다.

### Insight 2

기능 간 연결 구조 강화가 실제 행동 증가로 이어졌다.

### Insight 3

효과는 즉각적이지만 지속성은 낮았다.

### Insight 4

장기 리텐션 강화를 위한 후속 장치가 필요하다.
