# 채널 차이 (Channel Differences)

같은 이름, 다른 뜻 — 두 채널을 한 표에 붙이거나 채널 간 크기를 비교할 때 이 파일을 먼저 확인한다.

## Overview
- 대상 채널: 29CM `cm` · 무신사 `mss` · 무신사 글로벌 `mssglb` · 오프라인 `mssoff`
- 지표 이름은 시트 B열과 1:1
    - 이름이 같아도 **채널마다 세는 대상이 다른 지표**가 있음
- 이 파일에는 "어디가 다른가"만 기재 (산식 · 수치 미기재)
- 근거는 각 함수의 COMMENT `[주의]` 와 컬럼 COMMENT
    - 이 파일과 다르면 COMMENT 가 정답

## Answer Rules
- 두 채널 값을 한 표에 넣으면
    - **열 머리말에 채널 명시**
    - 아래 표에 걸리는 지표는 표 밑에 차이를 한 줄로 명시
- 채널 간 합계(예: 무신사 + 글로벌 GMV)
    - 아래 5. 더하면 안 되는 것에 걸리면 제공 금지
    - 사용자가 그래도 원하면 무엇이 섞이는지 먼저 안내
- 비율은 채널마다 단위가 다름
    - 표에 넣기 전에 단위를 맞추고 맞췄다고 명시

## 1. 커머스

| 지표 | 29CM | 무신사 | 글로벌 | 오프라인 |
|------|------|------|------|------|
| `GMV` 가 세는 금액 | 상품금액 기준 | 상품금액 기준, 상품권 구매 제외 | **상품금액 + 관세 + 결제수수료 + 배송비 + 판매세 + 반송비** | VAT 포함, 상품권 구매 제외 |
| `Net Take Rate` · `공헌이익률` 분모 | GMV / 1.1 | GMV / 1.1 | **GMV 원값** | GMV / 1.1 |
| `쿠폰할인` | 부담주체 축 롤업 | 종류 축 롤업(상품 쿠폰 + 장바구니 쿠폰) | 없음(프로모션할인으로 뭉쳐 있음) | 없음. `상품 쿠폰할인`(매장쿠폰 + O4O 상품쿠폰) + `장바구니 쿠폰할인`(O4O 장바구니쿠폰)을 더하면 쿠폰 전체 |
| `구매자 수 (GMV 기준)` | 취소 전용 주문의 회원 포함 | uid 기준, 취소·환불만 발생한 회원 포함 | uid 기준, 환불만 발생한 회원 포함 | **식별 회원만**(비회원 제외) |
| `주문 건수` · `평균판매단가` · `평균주문단가` | 전체 거래 | 전체 거래 | 전체 거래 | 전체 거래(회원·비회원). 구매자 수·객단가·인당 주문 건수와 모수가 다름 |
| 주문 건수 3종의 판매·클레임 구분 | `order` / `order_cs` 행 | `gmv_state` 1000 / 1060·1061·5060·5061 | `gmv_state` 1000 / 그 외(환불만, 교환 없음) | `sales_type` SALE / REFUND. `주문 건수 (GMV 기준)` 만 매장 번호를 붙여 셈. 다른 둘은 영수증 번호만이라 약 3% 작음 |
| `구매자 수 (판매행 기준)` | 있음 | 있음 (`sell_uid`) | 있음 | **없음** |
| 제외되는 거래 | 없음 | 상품권 구매 | 조조타운(ZZ)·티몰(TS) | 더미 주문·일부 매장 |
| `공헌이익액` 부호 | — | — | — | 고정비가 배부돼 음수가 나올 수 있음 |

- 글로벌 `GMV` · `평균판매단가` · `평균주문단가` · 각종 비율
    - 분자 · 분모에 배송비 · 관세 포함
    - 다른 채널과 **그대로 비교 금지**
- 판매분매입
    - 글로벌은 1P 산식, 오프라인은 3P 산식 적용
    - 1P 대 3P 로 나눠 보려는 요청이면 채널마다 묶임이 다르다고 안내

## 2. 프로덕트 (29CM · 무신사 · 글로벌)

| 지표 | 29CM | 무신사 | 글로벌 |
|------|------|------|------|
| 사용자 수의 단위 | 로그인 사용자 | 로그인 사용자(hash_id) | **client_id (기기·브라우저, 비로그인 포함)** |
| DAU · WAU · MAU 컬럼 | `DAU/WAU/MAU` 한 컬럼 | `DAU/WAU/MAU` 한 컬럼 | **`DAU` · `WAU` · `MAU` 세 컬럼** |
| WAU · MAU 구간 | 달력 주·월 | 달력 주·월 | **기준일 포함 최근 7일·30일 이동 구간** |
| 비율 단위 | 0 ~ 1 소수 | 0 ~ 1 소수 | **% 값(×100, 소수 둘째 자리)** |
| `방문 > 구매 전환율 (CVR)` | 구매자 / 방문자 | 구매자 / 방문자 | **주문수 / 활성 세션 수** |
| `상세 > 구매 전환율` | 구매자 / 상품상세 방문자 | 구매자 / 상품상세 방문자 | **주문수 / 상품상세 뷰수** |
| `전환율(CVR)` | 상품 클릭 사용자 / 상품 노출 사용자 | 상품 클릭 사용자 / 상품 노출 사용자 | **주문수 / 상품상세 뷰수** (`상세 > 구매 전환율` 과 같은 값. 다른 채널과 재는 단계가 다름) |
| `상품전환 사용자수` | 상품을 클릭한 사용자 | 상품을 클릭한 사용자 | **구매 사용자**(day 전용) |
| `방문 Stickiness dau/wau` | month 전용 | week 전용 | 없음 |
| `전환 Retention M+1` | 한 컬럼(상품 클릭 기준) | 상품상세·상품클릭 두 컬럼 | 없음 |
| `페이지 방문자수` | view_page 가 발생한 사용자 수 | page_view 가 발생한 사용자 수, 지면 구분 없음 | 지면 요약 마트의 PAGE 지면 목록 안 client_id distinct |
| `페이지 방문수` | view_page **발생 수** | page_view **발생 수**, 지면 구분 없음 | PAGE 지면이 있는 **세션 수**(session_id distinct). 이벤트 수가 아니라 그레인이 다름 |

- 글로벌 DAU 가 다른 채널보다 크게 보이는 이유의 대부분은 **비로그인 포함**
    - 채널 간 방문자 규모 비교에 사용 금지
- 글로벌 비율을 다른 채널과 나란히 놓으려면 100 으로 나눠 소수로 맞춤
    - 반대로 맞춰도 되지만 어느 쪽으로 맞췄는지 명시
- 글로벌 `MAU` 는 달력 월 값이 아님
    - "9월 MAU" 를 물으면 month 호출 값이 9/30 기준 최근 30일이라는 점을 먼저 안내

## 5. 더하면 안 되는 것
- **채널 간 방문자 · 구매자 합**
    - 사용자 식별자가 채널마다 다름 (로그인 · client_id · uid · 식별 회원)
    - 채널 간 중복 제거 불가
- **글로벌 GMV + 다른 채널 GMV**
    - 글로벌에만 배송비 · 관세 · 세금 포함
    - 합계가 필요하면 그 차이를 표 밑에 명시
- **비율의 채널 평균**
    - 분자 · 분모 정의가 달라 산술평균 · 가중평균 모두 의미 없음

## 7. 물류 · 운영 (무신사 전용)
- 다른 채널에는 없음
    - 물으면 "그 채널에는 정의가 없다"고 답변
- 출고 · 클레임 · 재고 계열 원천은 적재가 중단됨
    - 최근 기간을 물으면 값이 NULL 인 이유로 이것을 먼저 안내
- 피킹 UPH · 글로벌 SLA · 인입률은 현재까지 적재 중
