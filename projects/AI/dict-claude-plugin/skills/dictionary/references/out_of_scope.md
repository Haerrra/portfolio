# 범위 밖 (Out of Scope)

딕셔너리 시트에는 있지만 함수가 없는 지표를 정리한다.

## Answer Rules
- 아래 지표를 물으면 "딕셔너리 함수가 없다"와 이유를 답하고 중단
- 원천을 찾아 값 생성 금지
- 다른 채널 값으로 대체 금지

## Metric List

| 채널 | 지표 | 함수가 없는 이유 |
|------|------|------|
| 무신사 | 경영지원본부 지표 (Net take (accounting) · Variable cost · EBIT · EBITDA 등) | 재무 보고 쿼리를 따르는 지표이고, 일부 계정은 민감 정보라 DB 에 미적재 |
| 무신사 | 앱삭제 수 | 시트에 산식 없음 |
| 무신사 · 글로벌 | 유입 소스 | 지표가 아니라 유입 분류(organic · seo · referral 등) 설명 |
| 29CM | 상품상세 2Depth 전환율 | 29CM 상품상세 버튼 구조가 무신사와 달라 정의 불가. 1Depth 만 존재 |
| 29CM | 월 활성 세그먼트 Revisit 3종 | 29CM 에 대응하는 단계 없음 |
| 글로벌 | 광고사업 · 페이먼츠 전체 | 시트에 정의 없음 |
| 글로벌 | 문의 후 0 · 1 · 2 · 3개월 내 구매율 | 특정 기간 CS 문의 스냅샷을 쓰는 일회성 분석이라 기간 지표로 생성 불가 |
| 오프라인 | 커머스 외 전부 (프로덕트 · 광고 · 페이먼츠 · 마케팅) | 시트에 정의 없음 |

## Notes
- 시트에서 `N/A` 이거나 빈칸인 칸은 함수에도 없음
- 비슷한 지표가 있으면 **제안만** 함
    - 같은 채널의 다른 지표, 다른 채널의 같은 지표
    - 대신 조회해 "그 값"이라고 제공 금지
- 사용자가 그래도 원천에서 뽑아 달라고 다시 요청하면
    - 이 스킬의 범위 밖 작업이라고 명시
    - 결과 머리말에 `딕셔너리 지표 아님 · 정의 미확인` 과 사용한 테이블 · 식 기재
