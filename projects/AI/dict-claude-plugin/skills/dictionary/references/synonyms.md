# 동의어 사전 (Synonyms)

사용자 표현을 [지표 색인](metric_index.md)의 지표명으로 변환한다.

## Overview
- 사용자는 시트의 지표명이 아니라 평소 쓰는 말로 질문
- 지표명 근거는 딕셔너리 시트 C열(Description)
- 표에 없는 표현은 아래 Fallback 규칙 준수

## Decision Types

| 판정 | 뜻 | 행동 |
|------|------|------|
| **확정** | 후보가 하나 | 그 지표로 바로 조회. 답 머리말에 "○○ 은 `지표명` 으로 조회했다"를 한 줄 명시 |
| **병기** | 후보가 같은 계열이고 나란히 보면 오해가 없음 | 되묻지 않고 후보를 모두 조회해 열로 나란히 제공. 표 밑에 차이를 한 줄 명시 |
| **되묻기** | 후보끼리 뜻이 달라 하나를 고르면 틀릴 수 있음 | 조회하지 않고 후보를 보여 주며 선택 요청. 채널·기간·주기 질문과 **한 번에** 질문 |

### 되묻기 예시
- 후보마다 시트 정의를 반 줄로 첨부

```
"매출"은 딕셔너리에서 뜻이 여러 개라 하나를 골라 주세요.
  1) GMV — 교환·환불을 뺀 거래금액
  2) GGMV — 교환·환불을 빼기 전 판매금액
  3) Gross Take Amount — 회사가 가져가는 수수료 + 1P 매출총이익
채널(29CM / 무신사 / 글로벌 / 오프라인)과 기간도 같이 알려 주세요.
```

## 1. 커머스

| 사용자 표현 | 판정 | 지표 | 비고 |
|------|------|------|------|
| 거래액, 거래금액, 순거래액, 취소 반영 거래액 | 확정 | `GMV` | 시트 정의 "거래금액, 교환/환불 금액을 차감한 매출" |
| 총거래액, 판매금액, 취소 전 거래액, G-GMV | 확정 | `GGMV` | |
| 매출, 매출액, 실적, 판매액 | 되묻기 | `GMV` · `GGMV` · `Gross Take Amount` | 거래 규모인지 회사 수익인지 갈린다 |
| 할인 뺀 거래액, 순매출 | 확정 | `Net GMV` | |
| 결제액, 실결제액, 결제금액 | 확정 | `결제금액` | |
| 할인액, 할인 금액, 총할인 | 확정 | `총 결제 할인금액` | 하위 할인을 물으면 그 채널 색인의 할인 컬럼 |
| 할인율 | 되묻기 | `총 결제 할인율` · `자사부담 결제할인율` | 분모·분자가 다르다 |
| 우리가 낸 할인, 자사 할인 | 확정 | `자사부담 결제할인액` | |
| 브랜드 부담 할인, 업체 할인 | 확정 | `업체부담 결제할인액` | |
| 쿠폰 할인 | 확정 | `쿠폰할인` | 글로벌·오프라인에는 없다 → [채널 차이](channel_differences.md) §1 |
| 적립금 사용액, 포인트 할인 | 확정 | `적립금할인` | |
| 수수료 수익, 테이크, 매출총이익 | 확정 | `Gross Take Amount` | |
| 테이크율, 수수료율 | 되묻기 | `Gross Take Rate` · `Net Take Rate` | Net 은 자사부담 할인 차감 후 |
| 공헌이익, CP | 확정 | `공헌이익액` | |
| 공헌이익률, CP율, 마진율 | 확정 | `공헌이익률` | |
| 구매자 수, 구매 고객 수, 구매 회원 수 | 병기 | `구매자 수 (GMV 기준)` · `(GGMV 기준)` | 그 채널에 두 컬럼이 다 있을 때만 병기 |
| 주문 수, 주문 건수 | 병기 | `주문 건수 (판매행 기준)` · `(GMV 기준)` | SKILL.md 기준 규칙 |
| 판매량, 판매 수량, 팔린 개수 | 병기 | `판매수량 (GMV 기준)` · `(GGMV 기준)` | |
| 객단가, 인당 구매액, ARPPU | 병기 | `객단가 (GMV 기준)` · `(GGMV 기준)` | |
| 주문당 금액, 평균 주문 금액, 건단가, AOV | 병기 | `평균주문단가 (GMV 기준)` · `(GGMV 기준)` | |
| 평균 판매가, 상품당 판매가, ASP | 병기 | `평균판매단가 (GMV 기준)` · `(GGMV 기준)` | |
| 구매 빈도, 인당 주문 수 | 병기 | `인당 주문 건수 (GMV 기준)` · `(GGMV 기준)` | |

## 2. 프로덕트

| 사용자 표현 | 판정 | 지표 | 비고 |
|------|------|------|------|
| 방문자 수, 활성 사용자 수 | 확정 | 주기에 따라 DAU · WAU · MAU | 29CM·무신사 `DAU/WAU/MAU`(day = DAU), 글로벌 `DAU`·`WAU`·`MAU` 별도 |
| 일 방문자, 하루 방문자, DAU | 확정 | DAU (day) | |
| 주간 방문자, WAU | 확정 | WAU (week) | |
| 월간 방문자, MAU | 확정 | MAU (month) | |
| 로그인 방문자 | 확정 | `방문자 수 (로그인 기준)` | 29CM·무신사 마케팅 함수 |
| 구매전환율, 구매율 | 되묻기 | `방문 > 구매 전환율 (CVR)` · `상세 > 구매 전환율` | 분모가 전체 방문자인지 상품상세 방문자인지 |
| 전환율, CVR | 되묻기 | `방문 > 구매 전환율 (CVR)` · `상세 > 구매 전환율` · `전환율(CVR)` | `전환율(CVR)` 은 노출 → 클릭 사용자 전환 |
| 클릭률, CTR | 되묻기 | `상품 CTR` · `클릭률(CTR)` | 상품 노출 기준인지 노출 수 기준인지 |
| 상세 진입률, PDP 진입률 | 확정 | `방문 > 상품 전환율` | 상품상세 방문자 / 전체 방문자 |
| 상세 방문자, PDP 방문자 | 확정 | `상품상세 방문자수` | |
| 상세 조회수, PDP PV | 확정 | `상품상세 뷰수` | |
| 구매하기 클릭률 | 확정 | `상품상세 1Depth 전환율` | |
| 리텐션, 재방문율 | 되묻기 | `방문 Retention M+1` · `전환 Retention M+1` | month 전용. 무신사 전환 Retention 은 상품상세·상품클릭 두 컬럼 |
| 고착도, Stickiness | 되묻기 | `방문 Stickiness dau/wau` · `wau/mau` | 채널마다 채워지는 주기가 다르다 |
| 좋아요 수, 찜 | 되묻기 | `1인당 상품 좋아요 수` · `1인당 브랜드 좋아요 수` | |
| 세션 수 | 되묻기 | `활성 세션 수` · `노출 세션 수` · `클릭 세션 수` · `상품상세 세션 수` | |

| 사용자 표현 | 판정 | 지표 | 비고 |
|------|------|------|------|
| 광고비, 광고 매출 | 확정 | `광고 매출액` | 광고주가 집행한 광고비 = 무신사 광고 매출 |
| ROAS | 병기 | `광고 직접 기여 ROAS` · `광고 간접 기여 ROAS` | 퍼센트 값 |

| 무머니 결제액 | 확정 | `무머니 결제 거래액` | 무신사페이(토스페이먼츠)는 포함하지 않는다 |
| 무신사페이 결제액 | 범위 밖 | — | 무신사머니와 다른 결제수단. 딕셔너리에 없다 |
| 무머니 가입자 | 되묻기 | `무머니 연동 사용자 수` · `무머니 순연동 사용자 수` | 누적값. 해지 차감 여부 |

## Fallback — 표에 없을 때
1. [지표 색인](metric_index.md)에서 그 채널의 지표명과 직접 비교
    - 대소문자 · 띄어쓰기 · 괄호만 다르면 **확정**
2. 비슷한 지표가 둘 이상이면 **되묻기**
    - 하나를 골라 진행 금지
3. 하나도 없으면 [범위 밖](out_of_scope.md) 확인
    - 거기 있으면 이유와 함께 "딕셔너리에 없다"고 답변
4. 거기에도 없으면 "딕셔너리에서 찾지 못했다"고 답변
    - 사용자가 말한 정의를 받아 가장 가까운 지표 후보 2 ~ 3개 제시
    - 값 생성 금지

### 기준이 붙은 표현
- **표현에 기준이 붙어 있으면 그 기준이 우선**
    - "취소 반영 구매자 수" → `구매자 수 (GMV 기준)` 하나만
    - "원주문 기준 주문 수" → `주문 건수 (GGMV 기준)` 또는 `(판매행 기준)` 하나만
