## Overview

### Project Summary

운영 조직의 인력 운영 및 예산 계획 수립을 지원하기 위해 상품 판매 요청 수량 예측 모델을 구축하였다.

상품 판매 요청 수량은 검수 인력 수요와 직접적으로 연결되는 핵심 운영 지표이지만, 기존에는 경험 기반으로 인력 계획이 수립되고 있었다.

본 프로젝트에서는 Prophet 기반 시계열 예측 모델을 구축하고, 영업일 수·활성 브랜드 수·프로모션 규모와 같은 외생 변수를 활용하여 향후 판매 요청 수량을 예측하였다.

또한 판매 요청 수량에 영향을 미치는 주요 요인을 파악하기 위해 상관 분석을 수행하였다.

### Role

* Feature Engineering

* 상관 분석
* 결과 검증 및 리포팅

### Skills

# Business Problem

## Background

상품 판매 요청 수량은 검수 인력 운영 및 예산 계획 수립의 핵심 지표이다.

그러나 운영 조직은 향후 판매 요청 수량을 사전에 예측하기 어려워 인력 수요 산정이 경험 기반으로 이루어지고 있었다.

특히 프로모션 일정, 브랜드 증가, 영업일 수 변화 등의 요인에 따라 판매 요청 수량이 크게 변동하기 때문에 보다 체계적인 예측 체계가 필요하였다.

## Goal

향후 상품 판매 요청 수량을 예측하여

* 운영 인력 계획 수립
* 예산 집행 계획 수립
* 사업 목표 시뮬레이션

에 활용 가능한 모델을 구축한다.

# Methodology

## Forecasting Model

Prophet 기반 시계열 예측 모델을 적용하였다.

기본 시계열 패턴 외에 운영 환경을 반영하기 위해 외생 변수를 함께 활용하였다.

### Input Features

* 시계열 데이터
* 영업일 수
* 활성 브랜드 수
* 프로모션 참여 브랜드 수

# Model Evaluation

2022.12 ~ 2025.03 데이터를 학습한 후

# Correlation Analysis

판매 요청 수량에 영향을 주는 주요 요인을 파악하기 위해 상관 분석을 수행하였다.

## 1. 활성 브랜드 수

### Definition

해당 월 판매 중인 상품을 보유한 브랜드 수

### Result

상관계수

0.79

### Interpretation

활성 브랜드 수가 증가할수록 상품 판매 요청 수량도 뚜렷하게 증가하는 경향을 확인하였다.

높은 양의 상관관계가 나타났으며, 판매 요청 수량을 설명하는 주요 변수 중 하나로 판단된다.

[산점도 그래프 삽입]

---

## 2. 프로모션 참여 브랜드 수

### Definition

해당 월 시작된 프로모션에 참여한 브랜드 수

### Result

상관계수

0.66

### Interpretation

프로모션 참여 브랜드 수 역시 판매 요청 수량 증가와 관련이 있었으나, 활성 브랜드 수 대비 영향력은 다소 낮게 나타났다.

일부 월은 프로모션 규모가 커도 판매 요청 수량 증가가 제한적으로 나타나는 사례도 확인되었다.

# Key Findings

### Insight 1

Prophet 기반 예측 모델은 실제 운영 수요를 안정적으로 예측할 수 있었다.

### Insight 2

활성 브랜드 수는 판매 요청 수량과 가장 높은 상관관계를 보였다.

Correlation = 0.79

### Insight 3

프로모션 규모 역시 영향을 주지만 활성 브랜드 수보다 설명력이 낮았다.

Correlation = 0.66

### Insight 4

운영 조직은 본 예측 결과를 활용하여 검수 인력 및 운영 리소스를 사전에 계획할 수 있게 되었다.
