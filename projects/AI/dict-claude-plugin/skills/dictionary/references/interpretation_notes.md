# 해석 주의 (Interpretation Notes)

결과를 옮길 때 틀리기 쉬운 것을 정리한다. 어느 항목이든 함수 COMMENT 와 다르면 COMMENT 가 정답이다.

## 1. GMV 기준 vs GGMV 기준 — 같은 이름, 다른 값
- 29CM · 무신사: 아래 7종이 `(GMV 기준)` 과 `(GGMV 기준)` 둘 다 존재
    - 구매자 수 · 주문 건수 · 판매수량 · 인당 주문 건수 · 평균판매단가 · 객단가 · 평균주문단가
- 글로벌 · 오프라인: GMV 기준만 존재

### 기준별 의미
- GMV 기준: 취소 · 반품 행을 포함한 순액
    - 클레임만 있는 회원도 구매자로 집계
- GGMV 기준: 원주문(판매행)만
    - 취소 미반영

### 답변 규칙
- 기준을 말하지 않았으면 **두 열을 나란히** 제공
    - 표 밑에 취소 반영 여부를 한 줄 명시
    - 한 열로 합치거나 기준 표기 제거 금지
- 관례
    - 매출 관점 → GMV 기준
    - 유입 · 전환 관점 → GGMV 기준

### 1-1. 주문 건수는 3종

| 지표 | 세는 것 |
|------|------|
| `주문 건수 (판매행 기준)` | 그 기간에 결제된 주문 |
| `주문 건수 (GMV 기준)` | 판매 주문 − 교환·환불 주문 (처리일 기준이라 일 단위 음수 가능) |
| `주문 건수` | 판매·교환·환불 중 무슨 처리든 있었던 주문 전체. 클레임 업무량을 물을 때만 사용 |

- 기본은 판매행 기준 · GMV 기준 두 열
    - 29CM · 무신사의 `주문 건수 (GGMV 기준)` 은 판매행 기준과 같은 식이라 별도 제공 안 함
- 인당 주문 건수 · 평균주문단가 (GMV 기준)의 분모 · 분자는 `주문 건수`(전체)
    - 표 밑에 명시
- 오프라인
    - 판매행 기준 = 영수증 번호, GMV 기준 = 매장 + 영수증으로 집계
    - 두 열의 차이를 환불 건수로 해석 금지

## 2. 특정 주기에서만 채워지는 지표 — NULL ≠ 0
- [지표 색인](metric_index.md)의 `채워지는 주기` 가 정본
    - 다른 주기로 호출하면 NULL
- 주기 전용 지표
    - Stickiness · Retention → month (무신사 `dau/wau` 는 week)
    - 글로벌 `DAU` · `상품전환 사용자수`, `무머니 충전 사용자 수` → day 전용
- 사용자가 맞지 않는 주기로 요청하면 **먼저 안내** 후 주기를 바꿔 호출
- 일별 distinct 지표(충전 사용자 수 등)의 일별 값을 합산해 주간 · 월간 생성 금지
- 무신사 Retention 은 조회 범위 안에서 다음 달을 찾음
    - 마지막 달 행이 **0** 으로 나오지만 실제 값이 아님
    - `p_end_dt` 를 한 달 더 잡고 마지막 행 제외

## 3. 누적값과 스냅샷
- `무머니 연동 사용자 수` · `무머니 순연동 사용자 수` 는 누적값
    - month 로 호출하면 그 달 마지막 날 값
    - 일별 값 SUM 금지
- 월 활성 세그먼트 회원 수(New · 고활성 · 저활성 · 비활성-이탈-휴면)는 **월 1일 스냅샷**
    - day · week 로 호출하면 같은 달 안에서 값이 반복됨 (데이터 오류 아님)
    - 같은 세그먼트의 방문 유저 수 · 세션 수는 기간 행동이라 그레인이 다르다고 명시
- 물류 백로그 수량은 일별 스냅샷의 합
    - 기간 말 잔량이 필요하면 day 로 호출해 마지막 행 확인

## 4. 시트로 계산한 값과 다를 때
- 29CM `자사부담 결제할인액` · `업체부담 결제할인액` · `자사부담 결제할인율`
    - 함수가 추가할인 부담분을 포함해 시트 산식보다 큼
    - "시트랑 다르다"고 하면 이것부터 의심
- 그 밖의 차이는 정합성 테스트(`tests/consistency_check.py`) 결과에 기록된 것인지 확인

## 5. 다른 정의를 섞지 않는다
- 광고 `기여 거래액` 은 광고 플랫폼이 산정한 7일 기여 거래액
    - 정산 GMV 와 더하거나 나누기 금지
- `무머니 결제 거래액` 은 무신사머니만 포함
    - 무신사페이(토스페이먼츠) 미포함

## 6. 표로 옮길 때
- 비율은 소수 (글로벌 프로덕트 비율만 % 값, ROAS 는 퍼센트)
    - 퍼센트로 바꿔 보여 주면 "×100" 을 머리말에 명시
    - 이미 % 인 값을 다시 ×100 금지
- 금액은 원 단위
    - 억 · 만 단위로 줄이면 단위를 머리말에 명시
- week 의 dt 는 월요일, month 는 1일
    - "9월 1주"처럼 바꿔 쓰지 않고 dt 그대로 유지
- 범위는 `A ~ B` 꼴로 `~` 앞뒤에 공백 (마크다운 취소선 방지)
